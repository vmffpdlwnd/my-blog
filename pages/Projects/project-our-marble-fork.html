우리의 마블 (개인 확장)

팀 프로젝트를 포크해 전용 서버 없이 방장이 판정하는 구조로 바꾼 버전

GitHub → Play →

개요

팀 프로젝트 "우리의 마블" 클라이언트를 포크해 혼자 이어서 개발한 버전입니다. 팀 버전은 Spring 서버가 있어야만 플레이할 수 있어서, 서버가 꺼지면 게임도 끝납니다. 그래서 게임 파일 하나만 켜면 친구와 바로 할 수 있게 구조를 바꿨습니다. 웹(itch.io)과 Windows(.exe)로 배포했습니다.

문제 상황

  • 전용 서버와 Redis를 계속 운영하려면 비용과 관리가 든다
  • 서버 없이도 "요청 → 검증 → 결과 알림"이라는 서버 권위 흐름은 지켜야 한다
  • 방장이 나가거나 브라우저 탭이 뒤로 가도 게임이 멈추면 안 된다

내 역할

혼자 진행했습니다. 구조 설계부터 배포까지 맡았습니다.

  • 호스트 판정 구조: Photon Fusion Shared 모드의 마스터 클라이언트를 방장으로 쓰고, 방장이 규칙 판정, 봇, 제한 시간을 맡습니다. 참가자는 요청만 보내고 결과만 받습니다. 서버(Java)에 있던 규칙을 C#으로 옮기고, 호스트와 참가자가 같은 규칙 코드(Rules/)를 씁니다.
  • 방장 승계: 방장이 나가면 입장 순서대로 다음 사람이 방장이 되고, 자기 화면의 게임 상태를 복사해 호스트를 이어받은 뒤 모두에게 상태를 다시 보내 화면을 맞춥니다.
  • 재접속: 끊긴 사람의 자리를 남겨 두고 AFK로 대신 진행합니다. 같은 사람인지는 PlayFab 계정으로 확인하고, 3초 간격으로 최대 30초 동안 같은 방에 다시 들어갑니다.
  • 계정과 전적: SDK 없이 PlayFab REST API를 직접 호출합니다. 닉네임만으로 시작하는 익명 계정과 이메일 계정을 지원합니다.
  • 그 밖에 한/영 전환, 새 맵, 파산 신청, 황금열쇠 확장, 방 비밀번호를 추가했습니다.

성과

  • 전용 서버 없이 Photon과 PlayFab 무료 범위 안에서 운영합니다.
  • 웹과 Windows가 같은 방에서 함께 플레이할 수 있고, 연결에 실패하면 혼자 하기(오프라인)로 자동 전환됩니다.
  • 버전을 나눠 itch.io에 계속 배포하고 있습니다. (현재 v1.2)

트러블슈팅

웹에서 탭이 뒤로 가면 끊기는 연결

브라우저는 뒤로 간 탭의 실행을 멈추고, Photon은 10초 정도 신호가 없으면 연결을 끊습니다. 앱이 막을 수 없는 동작이라, 탭이 돌아오면 대기방과 게임 중 모두 같은 방에 자동으로 다시 들어가게 했습니다. 방장에게는 창이 뒤로 가도 계속 실행되는 Windows 버전을 안내합니다.

웹에서 한글 입력이 안 되는 문제

Unity 웹 빌드는 브라우저 입력기의 한글 조합을 입력칸에 전달하지 못합니다. 입력칸 위에 투명한 HTML 입력칸을 겹쳐 브라우저가 조합을 처리하게 하고, 글자를 Unity 입력칸에 실시간으로 넘기는 방식으로 해결했습니다.

게임 중 나가기가 방에 남는 문제

나가기가 화면만 로비로 바꾸고 연결은 게임 방에 남겨 둬서, 새 방을 만들 수 없고 방장이면 다른 사람의 게임이 멈출 수 있었습니다. 연결을 먼저 끊고 로비로 가도록 바꿔, 남은 사람에게는 끊긴 사람과 똑같이 처리되게 했습니다.

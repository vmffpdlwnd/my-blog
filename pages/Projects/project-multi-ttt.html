Multi_Ttt

말이 3개까지만 남는 틱택토와 Socket.IO 온라인 대전 서버

GitHub → Download →

개요

자기 말을 3개까지만 둘 수 있고, 4번째 수를 두면 가장 오래된 말이 사라지는 틱택토입니다. 로컬 2인, AI 대전, 온라인 대전을 지원하고, 온라인 대전용 Node.js 서버를 클라우드 VM에 직접 배포했습니다.

문제 상황

  • 일반 틱택토는 금방 무승부로 끝나서, 말이 사라지는 규칙으로 판을 계속 움직이게 하고 싶었다
  • 온라인 대전에서는 두 사람의 보드와 턴이 항상 같아야 한다

내 역할

혼자 진행했습니다.

  • 선입선출 규칙, 승패 판정, 기본 AI를 만들었습니다.
  • Socket.IO로 서버와 연결하고, 서버가 정한 플레이어 번호(1P/2P)로 턴을 관리합니다. 보드, 턴, 승자는 서버가 보내 주는 상태로 화면을 그립니다.
  • 다음에 사라질 말의 위치를 서버에서 받아 주황색으로 미리 보여 줍니다.
  • 상대의 입장(game_start)과 퇴장(player_disconnected)을 처리합니다.

성과

  • 서버를 직접 클라우드에 띄워 다른 PC끼리 실시간 대전을 할 수 있게 했습니다.
  • 로컬 2인과 AI 대전은 서버 없이도 플레이할 수 있습니다.

트러블슈팅

다시 시작하면 이전 판의 값이 남는 문제

새 게임을 시작해도 다음에 사라질 말 정보가 이전 판의 값으로 남아 있었습니다. 게임 데이터를 지우는 ResetGameData에 빠진 변수를 추가하고, 게임을 시작할 때마다 이 함수를 먼저 부르도록 바꿔 항상 깨끗한 상태에서 시작하게 했습니다.

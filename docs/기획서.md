# 포트폴리오 & 기술 블로그 기획서

**현재 상태:** 진행 상황과 할 일은 [작업 현황](작업현황.md)에 있다. ([사이트](https://vmffpdlwnd.github.io/my-blog))

## 1. 한 줄 요약

프로젝트 경험, 자격증, 기술 역량을 한눈에 보여주는 **인프라·시스템 엔지니어 포트폴리오**에, 공부한 내용을 쌓는 기술 블로그를 붙인 사이트.

## 2. 목표와 범위

### 목표
- 포트폴리오가 중심, 블로그는 보조 콘텐츠
- 외부 템플릿 없이 HTML / CSS / JS로 직접 구성
- 글은 노션에서 쓰고, 배포는 GitHub Actions로 자동화
- 무료 범위(GitHub Pages, GitHub Actions, Notion API, Giscus) 안에서 운영

### 포함
- Home: 한 줄 포지셔닝 소개, 핵심 역량, 기술 스택, 대표 프로젝트 2~3개, 최근 글
- Projects: 프로젝트 카드 목록, 상세(문제 상황, 내 역할, 구성도, 사용 기술, 성과, 트러블슈팅), GitHub 링크
- Blog: 기술 글 목록, 카테고리 필터, 정렬, 고정글, 글 본문 + Giscus 댓글
- Resume: 학력, 자격증, 군 경력, 기술 스택, 프로젝트 요약 + PDF 저장 버튼

### 제외
- 이 사이트(my-blog) 자체는 포트폴리오 프로젝트로 올리지 않는다. 블로그로 쓰는 프로젝트이기 때문이다.

## 5. 시스템 아키텍처

```
Notion DB ──(Notion API, 토큰은 GitHub Secrets)──▶ GitHub Actions ──▶ notion-sync.js ──▶ build.js ──▶ GitHub Pages
방문자 댓글 ──▶ Giscus ──▶ GitHub Discussions
```

- 새 글 반영: `main`에 push, 매일 06:00(KST) 자동 실행, Actions 탭의 수동 실행
- Pull Request에서는 빌드만 확인하고 배포하지 않는다
- 빌드 실패 시 GitHub Actions 로그로 원인을 확인한다

## 6. 노션 데이터베이스 설계

| 노션 속성 | 타입 | 역할 | 글 HTML |
| --- | --- | --- | --- |
| 제목 | Title | 글 제목 | `<title>` |
| 날짜 | Date | 작성일, 정렬 기준 | meta date |
| 카테고리 | Multi-select | 필터 버튼, 태그 | meta category |
| 고정 | Checkbox | 상단 고정 | meta pinned |
| 발행 | Checkbox | 체크한 글만 사이트에 공개 | |
| 요약 | Text | 글 상단 한 줄 요약 (비워 두면 생략) | `<p class="post-subtitle">` |

- 카테고리 값은 영문 키(`network`, `linux`, `jungcheoki`)로 관리하고, 화면 이름은 `assets/main.js`의 `categoryLabel`과 `scripts/notion-sync.js`의 `CATEGORY_LABEL`에서 매핑한다.
- 노션 이미지 주소는 약 1시간 뒤 만료되므로 동기화 때 내려받아 `assets/images/`에 저장하고 HTML에는 저장된 경로를 넣는다.
- 속성 이름은 `scripts/notion-sync.js`의 `PROP`과 같아야 하고, 노션 통합(Integration)이 데이터베이스에 연결되어 있어야 한다.

## 7. 보안 원칙

- 노션 토큰, 데이터베이스 ID 등 비밀 값은 코드에 넣지 않고 GitHub Secrets와 로컬 `.env`에만 저장한다.
- 저장소가 공개이므로 코드, 글, 이력서의 모든 내용이 공개된다. 이력서에는 공개해도 되는 연락처·주소만 기재한다.
- 노션의 비공개 메모는 `발행`을 체크하지 않으면 사이트에 올라가지 않는다.
